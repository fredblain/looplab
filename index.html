See what a loop does, one line at a time

A loop repeats the same few lines, and each round some variables get new values. Most loop mistakes happen because those values are invisible. Loop Lab shows them: you run short Python programs step by step, predict what happens next, and check yourself straight away.

Three activities do them in this order

1

Step through

Watch a loop run line by line.

  • Pick a program from the menu and press Step. The programs are numbered: take them in order, from easier to harder.
  • With Predict on, you type the new value of a variable (or what gets printed) before Python shows it.
  • The Spot the bug programs are broken. Find the step where it goes wrong, then press Edit code to fix it.
  • You can also type and run your own loops.
Open Step through
2

Trace table

Be the computer.

  • Fill in the trace table yourself, one row per line that Python runs.
  • For each row, write the value of every variable after that line, and anything it prints.
  • Every cell is checked. After two wrong tries you can reveal the row.
  • This is the same skill you need for paper exercises and exams.
Open Trace table
3

Line puzzles

Build a loop from the lines given.

  • All the lines you need are given, shuffled. Drag them into order, and drag left or right to indent them.
  • One line in each puzzle is a trap: it looks right but does not belong.
  • Check tests your program on several inputs.
  • Watch it run opens your answer in Step through.

When you are stuck
  1. Say out loud what you expect after each step.
  2. Step until the first value that surprises you.
  3. The mistake is in that line, or just before it.
  4. Still stuck? Show your teacher the step number.
Shortcuts
  • → next step, ← step back (in Step through)
  • Enter checks your answer
  • Tab inserts 4 spaces in the code editor
What Python works here

Variables, numbers, strings, lists, for, while, if / elif / else, break, continue, print, range, len, min, max, sum, .append(), slices like word[1:3] and word[::-1], and common string methods (.upper(), .split(), .replace(), .find(), .startswith(), ...).

Not supported: functions (def, return), input(), f-strings, dictionaries. Programs stop after 300 steps, so an endless loop cannot freeze the page.

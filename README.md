# Tutorial: Loops in Python

## Loop Lab (interactive)

Open **`index.html`** in any web browser (double-click it). It opens on a **Start** page that
explains the screen and the activities, then has three activities:

- **Step through**: run a loop one line at a time and watch the variables change. With *Predict* on,
  you type what will happen before Python shows you. You can also edit the code and run your own.
- **Trace table**: fill in the trace table yourself, row by row, and get instant feedback.
- **Line puzzles**: 30 puzzles in 7 sections (for each item, count and filter, best so far, positions
  and range(), while, break, nested loops). Drag shuffled lines into order and indent them correctly
  (one line is a trap). Progress can be reset from the Start page or the puzzles tab.

It works offline. It runs a small subset of Python written for this tutorial (variables, numbers,
strings, lists, `for`, `while`, `if`, `break`, `print`, `range`, `len`, ...), not full Python.
